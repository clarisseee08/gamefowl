# Documentation

Every document in this repository, what it's for, and whether it still describes
the system as it is. When a document and the code disagree, the code wins.

The three files that stay at the repository root:

| File | What it is |
|---|---|
| [`README.md`](../README.md) | The project's front page: what the system does, how to install and run it. |
| [`CLAUDE.md`](../CLAUDE.md) | Standing rules for anyone, human or AI, working in the code. Claude Code reads it from the root, so it can't move. |
| [`AGENTS.md`](../AGENTS.md) | Laravel Boost's guidelines for AI tools other than Claude Code. Generated by Boost at the root; don't edit by hand. |
